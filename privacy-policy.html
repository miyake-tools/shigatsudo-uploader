ホームプライバシーポリシー

最終更新日：2026年11月13日

四月堂 Uploader（以下「本ツール」）は、YouTubeチャンネル「四月堂」の運営者が個人で使用する動画アップロード用ツールです。本ポリシーは、本ツールが取り扱う情報について説明します。

1. 取得する情報

本ツールは、Google OAuth 2.0 による認証を通じて、YouTubeへの動画アップロードに必要なアクセス権限（https://www.googleapis.com/auth/youtube.upload）のみを取得します。氏名・住所・連絡先などの個人情報を収集することはありません。

2. 利用目的

取得したアクセス権限は、運営者本人のYouTubeチャンネルへ動画をアップロードし、タイトル・説明文・公開設定を登録する目的にのみ使用します。

3. 情報の保存

本ツールが保存するのは認証トークン（ログイン情報）のみです。認証トークンは本ツールを実行しているパソコン内にのみ保存され、ユーザーが削除するか、アクセス権を取り消すまで保持されます。外部のサーバーへ送信・保存することはありません。

動画やチャンネルに関するデータを本ツールが保存することはありません。

4. 第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。

5. Google API の利用について

本ツールは YouTube API サービスを使用しています。本ツールによるGoogle APIから受け取った情報の使用は、Google API Services User Data Policy（限定使用要件を含む）に準拠します。

YouTube 利用規約：https://www.youtube.com/t/terms
Google プライバシーポリシー：https://policies.google.com/privacy

6. アクセス権の取り消し

本ツールへのアクセス権限は、Googleアカウントの「サードパーティのアプリとサービス」からいつでも取り消すことができます。
・https://myaccount.google.com/connections
・https://security.google.com/settings/security/permissions
パソコン内のトークンファイルを削除することでも、保存された情報は消去されます。
