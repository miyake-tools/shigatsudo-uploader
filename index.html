四月堂 Uploader

ホームプライバシーポリシー

四月堂 Uploader は、YouTubeチャンネル「四月堂」の運営者が個人で使用する動画アップロード用のデスクトップツールです。

主な機能

パソコン内の動画ファイルを、YouTube Data API v3 を使って運営者自身のYouTubeチャンネルへアップロードします。あわせて、動画のタイトル・説明文・公開設定を登録します。

Googleアカウントの利用について

Googleアカウントへのアクセスは、運営者本人のチャンネルへ動画をアップロードする目的にのみ使用します。取得した情報を第三者に提供することはありません。

詳しくは「プライバシーポリシー」をご覧ください。
